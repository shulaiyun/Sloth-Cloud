# Code of Conduct

Sloth Cloud is intended to be a practical, respectful engineering community.

## Expected Behavior

- Be kind, specific, and constructive.
- Assume good intent, but do not ignore harmful impact.
- Help newcomers understand the project boundary and safety rules.
- Keep disagreements focused on code, docs, product behavior, and evidence.
- Respect that maintainers may decline scope that increases legal, security, or operational risk.

## Unacceptable Behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Publishing secrets, customer data, private infrastructure details, or exploit instructions.
- Pressuring maintainers to merge unsafe code or vendored third-party panel source.
- Repeatedly derailing issues or PRs after maintainers have set scope.

## Reporting

For security issues, follow `SECURITY.md` and do not open a public issue with sensitive details.

For community issues, contact a maintainer privately when possible. Maintainers may edit, hide, lock, or remove content that violates this code of conduct.
