# 树懒云智能运营助手使用说明

## 1. 这是什么

树懒云前台右下角的 `AI` 悬浮按钮，就是当前客户端接入的智能运营助手。

它不是演示玩具，当前接法分成两层：

- 业务数据层：读取树懒云当前登录用户、服务、账单、运行状态
- 模型层：当前 Mac 环境已接到本机 `OpenClaw` 网关，再由 `OpenClaw` 调度模型回复

## 2. 从哪里进入

当前可用入口有 2 种：

- 前台页面：`http://localhost:3000`
- 接口方式：`http://127.0.0.1:4000/api/v1/assistant/*`

说明：

- `http://127.0.0.1:4000` 不是前台页面，它是 API 端口
- 真正给你点按钮、登录、使用机器人的页面，是 `http://localhost:3000`

## 3. 现在能做什么

### 3.1 游客状态

未登录时，助手可以：

- 介绍平台功能
- 回答购买前咨询
- 给出排障建议
- 引导你登录后执行具体动作

### 3.2 登录后

登录后，助手可以读取当前账号上下文，支持：

- 查询服务状态
- 查询开通状态
- 查询运行状态
- 查询账单状态
- 生成可执行动作建议
- 执行低风险动作
- 对高风险动作先要求确认，再执行

## 4. 目前支持的动作

### 4.1 只读类

- 查看服务状态
- 查看开通进度
- 查看运行状态
- 查看账单状态

### 4.2 低风险动作

这类动作可以直接执行：

- 重试开通
- 重启实例
- 同步运行状态
- 转人工支持

### 4.3 高风险动作

这类动作必须二次确认：

- 取消服务
- 续费服务
- 删除运行实例

## 5. 最常见的用法

你可以直接自然语言说：

- `这个平台可以做什么？`
- `帮我看看服务 #46 的状态`
- `帮我重试开通 #46`
- `帮我重启服务 #46`
- `帮我同步服务 #46 的运行状态`
- `帮我给服务 #46 续费`
- `帮我取消服务 #46`
- `把这个问题转人工`

## 6. 页面上下文怎么用

助手会自动读取你当前所在页面：

- 在 `/services/:id` 页面，会自动带上当前服务编号
- 在 `/invoices/:id` 页面，会自动带上当前账单编号

所以你在服务详情页里通常不用反复输入服务号，直接说：

- `帮我重启一下`
- `看看开通卡在哪`
- `帮我同步状态`

## 7. 具体如何操作

### 7.1 前台里使用

1. 打开 `http://localhost:3000`
2. 点击右下角 `AI`
3. 直接输入问题
4. 如果出现动作卡片，可以直接点执行
5. 如果是高风险动作，先确认再提交

### 7.2 通过接口使用

可用接口：

- `GET /api/v1/assistant/capabilities`
- `POST /api/v1/assistant/session`
- `POST /api/v1/assistant/messages`
- `POST /api/v1/assistant/actions/confirm`

典型流程：

1. 先创建会话
2. 发送消息
3. 如果返回待确认动作，再提交确认

## 8. 风控规则

当前助手遵循下面这些规则：

- 不会把高风险动作直接静默执行
- 未登录时不会替你执行账号动作
- 没有明确服务号时，不会冒然执行服务级操作
- 执行结果以真实业务接口返回为准，不会伪造“成功”

## 9. 当前这版的边界

当前已经接通：

- 前台悬浮助手
- 本机 `OpenClaw`
- 真实账单/服务接口
- 低风险自动执行
- 高风险确认执行

当前暂时不等价于：

- Telegram 机器人入口
- 微信入口
- 企业 IM 入口

这些入口以后可以扩展，但目前树懒云客户端里已经落地的是网页悬浮助手和对应 API。

## 10. 排错

### 10.1 为什么 `127.0.0.1:4000` 看起来不像页面

因为这是 API 端口，不是前端站点。

应该使用：

- 前台：`http://localhost:3000`
- 健康检查：`http://127.0.0.1:4000/api/v1/health`

### 10.2 机器人打不开或不回复

优先检查：

- 前台是否打开在 `3000`
- API 是否存活
- 是否已经登录
- 当前服务号/账单号是否存在
- `OpenClaw` 网关是否在线

### 10.3 执行动作没反应

先确认：

- 该动作是不是高风险动作
- 当前账号是否已登录
- 当前服务在本地数据里是否存在
- 上游服务是否在线
